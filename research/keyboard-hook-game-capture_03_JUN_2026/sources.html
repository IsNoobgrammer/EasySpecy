Methodology Summary

Our research analyzed why WH_KEYBOARD_LL fails to record keystrokes specifically when active game windows (such as Dead Cells) are focused, while successfully capturing keys during standard desktop tasks (file navigation, text fields, etc.).

Three main constraints were cross-referenced: privilege boundaries (UIPI), raw input bypassing, and anti-cheat hooks. The consensus points to privilege matching as the primary, immediate fix for users, and Raw Input API design as the secondary structural developer workaround.
